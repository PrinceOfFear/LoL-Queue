# Fontes dos assets visuais

Os arquivos são armazenados localmente para a interface funcionar sem rede e
para que uma mudança de URL não quebre um build já distribuído.

- `spells/flash.png` e `spells/barrier.png`: Riot Games Data Dragon 16.17.1.
  - `https://ddragon.leagueoflegends.com/cdn/16.17.1/img/spell/SummonerFlash.png`
  - `https://ddragon.leagueoflegends.com/cdn/16.17.1/img/spell/SummonerBarrier.png`
- `ranks/iron.png` até `ranks/challenger.png`: pacote oficial de emblemas
  para desenvolvedores da Riot Games, `ranked-emblems-latest.zip`.
  - `https://static.developer.riotgames.com/docs/lol/ranked-emblems-latest.zip`
- `ranks/all.png`, `positions/*.png` e `maps/*.png`: assets do cliente do
  League preservados pelo CommunityDragon, snapshot `16.17`.
- `fonts/*.otf`: famílias Spiegel e Beaufort for LOL do cliente, snapshot
  `16.17` preservado pelo CommunityDragon.

CommunityDragon é um projeto comunitário e não representa endosso da Riot.
LoL Queue também é um projeto independente e não é endossado pela Riot Games.
League of Legends e todas as propriedades associadas pertencem à Riot Games,
Inc.
