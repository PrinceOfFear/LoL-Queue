LoL Queue — instalação compatível via Python

Use esta versão somente se o Windows bloquear o executável portátil por causa
do Smart App Control ou de uma política corporativa. Ela contém o código Python
do app e usa o pythonw.exe assinado pela Python Software Foundation para abrir
o LoL Queue.

Como instalar
1. Extraia o ZIP inteiro para uma pasta permanente. Não a apague depois.
2. Abra o PowerShell dentro dessa pasta.
3. Rode:

   powershell -ExecutionPolicy Bypass -File tools\instalar.ps1

4. Se o Python ainda não estiver instalado, o instalador mostrará o link
   oficial. Instale Python 3.13 ou mais recente, marcando "Add python.exe to
   PATH", e repita o passo 3.
5. Ao terminar, abra o atalho "LoL Queue" criado na Área de Trabalho.

Antes de instalar
- Na primeira abertura, informe a chave recebida na assinatura mensal do
  LoL Queue. Ela fica vinculada a este computador e não deve ser copiada para
  outro PC.
- Confira o arquivo .sha256 entregue junto com o ZIP, se disponível.
- Para recursos do League (fila, seleção, histórico e PDL), abra o cliente do
  League of Legends e entre em uma conta normalmente.

Depois de instalar, abra Ajustes > Verificar segurança no LoL Queue. A
verificação usa o selo assinado que acompanha a pasta para detectar arquivos
alterados, removidos ou adicionados, sem enviar dados da sua conta.

Esta alternativa existe para não incentivar a desativação das proteções do
Windows. Para uma distribuição por .exe que funcione em larga escala sem esse
passo extra, é necessário assinar o aplicativo com um certificado público de
code signing confiável.
