# LoL Queue 0.2.2

- Runas de confronto passam a aparecer quando o guia do OP.GG sustenta mais
  de uma página: a opção mais jogada continua como padrão e a de maior taxa
  fica disponível para aplicação manual, com a amostra visível no tooltip.
- Cada página é criada somente a partir de uma combinação completa de runas
  devolvida pelo guia; o app não monta uma página sintética escolhendo runas
  de árvores diferentes.
- O botão de confronto no painel identifica o adversário e o critério da
  página, mantendo as opções de elo no mesmo seletor.
