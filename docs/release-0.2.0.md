# LoL Queue 0.2.0

- Remove completamente do LoL Queue o sistema experimental de aviso de JG: captura do minimapa, detecção, voz, ajustes e ferramentas de calibração.
- Mantém intactas as rotas normais da fila, as builds, o histórico, a análise e a proteção de chat durante a seleção.
- Reduz o tamanho e as dependências da instalação, removendo componentes que só existiam para esse recurso.
- A base completa do aviso de JG ficou arquivada separadamente para um futuro projeto próprio.
